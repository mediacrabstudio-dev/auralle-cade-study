(04)Process

Photoreal stills

Blender sets the layout. Each frame is then lifted to photography, matched to a real reference for hard sun, crisp shadow and a clean new-build feel.

The method

Shot, not generated.

  • 1. Layout from BlenderCamera, lens and composition come from the 3D model, so the building never changes between shots.
  • 2. Look referenceA real terrace photograph sets the light: late-morning sun, deep blue sky, light haze.
  • 3. Photoreal passEach render is lifted to a photograph with the same recipe, then checked against the model.
  • 4. GradeGentle contrast, cooler shadows, foliage pulled back so it reads as one shoot.
Times of day

Morning to blue hour.

The same house, photographed through a full day: sunrise mist, hard midday, golden hour on the terrace, a monsoon dinner and the villa lit from the beach.
